## Overview
This repository contains 15 SQL queries and their expected tabular outputs for the BrightLearn SQL Aggregates & Operators exercise, demonstrating data aggregation, grouping, and multi-condition filtering techniques.

## Contents
- **`solutions.sql`**: SQL queries utilizing aggregate functions (`COUNT`, `SUM`, `AVG`, `MIN`, `MAX`), `GROUP BY`, `HAVING`, column aliasing (`AS`), and filtering operators (`BETWEEN`, `IN`, `NOT`, `ORDER BY`, `LIMIT`).
- **`outputs.md`**: Expected tabular outputs derived from the `students`, `courses`, `enrollments`, `salaries`, and `projects` datasets.

## Datasets Covered
- **`students`**: Grouping and demographic range filtering.
- **`courses`**: Aggregation with `HAVING`, sorting, and result limiting.
- **`enrollments`**: Statistical summary aggregates (`MAX`, `MIN`, `AVG`) and course enrollment counts.
- **`salaries`**: Grouped payroll sums, average threshold filtering, and row-level arithmetic expressions.
- **`projects`**: Budget aggregates and multi-condition departmental exclusions.
